# ChordRoom Plus

A static scale harmony explorer built with HTML, CSS, JavaScript, and the Web Audio API. The original Chord Room app remains in the parent directory.

## Run locally

Open `index.html` in a modern browser, or serve this folder with `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Deploy

Deploy this folder as a static site on GitHub Pages, Netlify, Cloudflare Pages, or any host that serves HTML, CSS, and JavaScript. There is no build step or server runtime.

## Included

- Tonic and scale selectors for major, minor, common modes, pentatonic and blues scales, plus double harmonic (often called Oriental)
- A two octave keyboard that enables only notes from the selected scale as chord roots
- Diatonic triads built on the selected scale degree, with note names, intervals, and scale degrees shown
- Simultaneous chord playback in soft piano, warm keys, or glass synth voices
- Volume control and highlighted chord tones
